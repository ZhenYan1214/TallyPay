Tieout · static web app, no server

1Pay & request

Builds one Multicall3From batch: a run anchor plus a memo-tagged USDC transfer per payee. Payment-request links let a payee put its invoice id into the payer's memo.

2Read the chain

ERC-20 and EIP-7708 transfer logs in both directions, Memo events, receipts for fees, balances at both ends of the range. Chunked by 9,000 blocks.

3Reconcile

Memo → reference → manual → intent, strongest evidence first. Ambiguity is held, never guessed. Run-anchor check and balance roll-forward to the wei.

4Book & export

Balanced journal entries, exceptions to suspense. Xero, QuickBooks Online, ISO 20022 camt.054, and an audit bundle anyone can re-run.
